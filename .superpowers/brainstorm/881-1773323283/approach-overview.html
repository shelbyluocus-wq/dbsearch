Liquid Glass UI 改造方案

基于 Demo.jsx 的视觉方向，应用到整个面板窗口

核心思路：三层叠加架构

将面板窗口改为三层结构，天气动效透过半透明 UI 层呈现

三层架构概览

底层：天空渐变 → 中层：天气粒子 → 顶层：毛玻璃 UI
透明度 60-75%，天气透过面板若隐若现

改造范围

1

主面板 → Liquid Glass

标题栏、侧边栏、内容区、底部栏全部改为半透明毛玻璃，天气动效从背后透出。搜索框和卡片有独立的 glass 层级

2

全部弹窗 → 统一 Glass 风格

表详情、结果放大、新建文件夹、编辑对话框、导出对话框等全部统一使用 settings-modal-v2 的毛玻璃效果 + 弹入动画

3

天气调试彩蛋 → Glass Popover

点击标题5次弹出浮动气泡式面板，包含天气/时间/画质控制。iOS 弹簧动画 (cubic-bezier overshoot)

4

天气背景 → Demo.jsx 效果

新增时间驱动的天空渐变（黎明/白天/黄昏/深夜），CSS 动画雨滴、浮动云朵、太阳弧线、夜间星空

可读性保障策略

中度透明（60-75% 白色）+ backdrop-filter blur(20-40px) + 白色边框高光 + 文字保持深色不变。
效果类似 Apple visionOS：通透但不模糊文字。天气越恶劣，天空越暗，反而增强对比度。
