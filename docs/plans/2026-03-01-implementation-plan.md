## 一、 核心视觉隐喻 (Visual Metaphor)

- **阅读视图（默认）：** “宁静的白纸” —— 采用无边框或极淡的边框线，大面积留白，传递“安全、无害、纯粹浏览”的绝对安全感。
- **编辑视图（开启）：** “激活的控制台” —— 通过边缘唤醒的光效，暗示系统已进入“可修改的高能状态”，提升用户的警觉性。

## 二、 “Apple Intelligence 风格” 防误触光效全生命周期设计

我们将整个编辑模式的光效生命周期拆分为 **4 个关键帧阶段**，并为每个阶段定义精确的动画曲线（Easing）和物理隐喻。

### 阶段 1：点火与破局 (入场动画)

**触发时刻：** 用户输入日期密码并点击“验证通过”的瞬间。

- **视觉路径：** 光点并非凭空出现，而是**起源于右上角的“切换开关 (Toggle)”处**。
- **动画表现 (0s - 0.6s)：**
    - 一颗高亮的“能量点”从开关处迸发，分为两股光束，以极快的速度沿着屏幕（或数据表格容器）的上沿和右沿**双向“跑马灯”式蔓延**。
    - 光束在交汇于对角线或底部后，迅速闭合，点亮整个边框。
- **动效曲线 (Easing)：** `cubic-bezier(0.22, 1, 0.36, 1)` (快速冲刺，柔和减速，模仿能量注入的物理惯性)。

### 阶段 2：高能涌动 (幻彩流动期)

**触发时刻：** 光环闭合后 (时长维持约 2.4 秒)。

- **视觉表现 (0.6s - 3.0s)：**
    - 边框变宽并产生强烈的**霓虹模糊效果 (Glow Blur)**。
    - 颜色呈现类似 Apple Intelligence 的 **极光幻彩色 (Aurora Gradient)** —— 混合了青蓝、紫红、亮橙等高能色彩。
    - 色彩不是静止的，而是沿着边框像液体一样**缓缓流动交融**（通过 CSS `background-position` 动画实现）。
- **动效曲线 (Easing)：** `linear` (匀速流动，保持平稳的呼吸感，避免给用户造成急躁的心理暗示)。

### 阶段 3：冷却固化 (工作常驻期)

**触发时刻：** 进入编辑模式 3 秒后。

- **视觉表现 (3.0s - 3.5s)：**
    - 出于“防视觉疲劳”的考虑，炫酷的幻彩流动**开始褪色**。
    - 渐变色互相融合，最终“降温”定格为一种**单一且明确的主题警示色**（推荐：不刺眼的“警戒琥珀黄” `#F59E0B` 或“专注静谧蓝” `#3B82F6`）。
    - 边框的极其发散的 Glow (发光) 效果收敛变窄，变成一条清晰、锐利的 2px/3px 实体常驻边框。
- **动效曲线 (Easing)：** `ease-in-out` 或 `cubic-bezier(0.4, 0, 0.2, 1)` (平滑过渡，不显得突兀)。

### 阶段 4：能量抽离 (退场动画)

**触发时刻：** 用户点击“退出编辑”（且没有未保存项）或点击“提交保存”并退出的瞬间。

- **视觉表现 (0s - 0.4s)：**
    - 绝不是生硬的瞬间消失（切断电源）。
    - 固化的边框线会迅速失去亮度（Opacity 从 100% 降至 0%）。
    - 同时，边框会有一个向内“**微微收缩 (Scale 0.99)**”并向着最初的“切换开关”处**逆向回退吸收**的动画。隐喻“能量被成功封存”，数据被安全锁定。
- **动效曲线 (Easing)：** `cubic-bezier(0.5, 0, 0, 1)` 或 `ease-out` (起步快，结束干净利落，给予一种“完成/安全”的释然感)。

## 三、 防误触与容错机制交互补全

除了顶级的光效，基础的交互逻辑也必须严丝合缝：

1. **打断与还原机制：**
    - 如果在**“阶段 2（流动期）”**用户就闪电般点击了退出，动画不应卡顿等待 3 秒播完，必须**立刻打断**当前进程，直接切入预设好的**“退场动画”**，保证操作的实时响应 (Responsive)。
2. **验证弹窗的微交互：**
    - **失败动效：** 用户手滑输入错误日期时，输入框触发经典的**“左右抖动 (Shake)”反馈**，同时边框变红，物理反馈极强。
    - **自动聚焦：** 点击“进入编辑”调出弹窗时，鼠标焦点应**自动落在密码输入框**，无需用户再次点击。输入满 8 位正确日期后，建议**自动解锁**并散发光圈，无需再点“确认”按钮（达到极致流畅体验）。
3. **草稿未保存时的状态提示：**
    - 当用户在单元格中修改了数据但未提交（草稿状态），该特定**数据行的背景色**需呈现与边缘固化色**同色系的极浅背景**（例如边框是蓝色，被修改行就是 `rgba(59, 130, 246, 0.05)`），形成设计语言的一致性暗示。
    - 底部悬浮的【💾 保存更改】按钮，在其左侧增加一个小巧的呼吸红点指示器，强提示“有数据正挂在内存中等待写入”。

### 技术实现备忘 (Technical Notes)

为实现上述如同原生 App 般丝滑的边缘发光效果，建议前端采用以下方案：

- **避免重排：** 绝对不要使用改变 DOM 实际宽高的 CSS 属性做动画，用 `::before` / `::after` 伪元素脱离文档流进行定位。
- **幻影流光层：** 使用一个带有 `padding` 和 `border-radius` 的大容器罩在表格上，利用 `mask-image` (CSS 遮罩) 或 `background: conic-gradient()` 配合 `animation: spin` 来实现四周的光子流窜和渐变流动。
- **性能保障：** 在动画的 CSS 类上追加 `will-change: transform, opacity;` 交由 GPU 加速，确保 60fps 满帧运行，防止在庞大数据表格上出现掉帧。

这份方案从宏观的防误触逻辑，包揽了到微观的 0.1 秒级别贝塞尔曲线的动画定义。它不仅解决了安全问题，更能在用户解锁编辑状态时，提供极为惊艳的情绪价值。
