# 标题栏数据库切换与页签样式设计

**背景**

当前数据库连接状态显示在标题栏最右侧，而数据库模板切换控件位于底部页脚，两者信息分散。顶部页签采用气泡标签样式，与用户希望的“默认接近纯文本、悬停再浮现背景”的桌面菜单感不一致。

**目标**

1. 将数据库模板快速切换控件迁移到标题栏页签区域附近。
2. 将数据库连接状态与数据库切换控件并列显示，形成同一信息组。
3. 将顶部页签调整为文本优先样式：
   默认状态更像有间距的文字条目。
   悬停时显示背景与关闭按钮。
   当前激活项保留轻量强调，但不再使用气泡标签外观。

**方案**

1. 在标题栏 `titlebar-shelf-wrap` 内新增数据库切换组，放在页签条右侧，与天气和设置按钮区分开。
2. 移除底部 `panel-footer` 中的模板快速切换条，避免同一功能出现两处。
3. 数据库切换组包含：
   上一模板按钮、当前模板名、下一模板按钮、连接状态点、数据库名。
4. 提取标题栏数据库切换组显示逻辑为纯函数，确保在“已断开但仍存在模板”时仍可显示切换入口。
5. 页签交互样式改为：
   默认透明背景、弱边框/无边框、较小内边距、关闭按钮隐藏。
   悬停时显示背景、边框和关闭按钮。
   激活态使用轻度底色与更高文本权重，不做明显圆角气泡抬升。

**影响范围**

- `src/App.vue`
- `src/styles.css`
- `src/panelChrome.js`
- `src/panelChrome.test.js`

**验证**

1. 单元测试覆盖标题栏数据库切换组显示逻辑。
2. 运行相关 node test 文件。
3. 运行前端构建，确认模板和样式改动未破坏编译。
