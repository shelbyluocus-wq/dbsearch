# 全屏 Schema 浮动窗口设计

## 背景

表数据全屏查看时，Schema 信息当前作为顶部固定浮层展开。用户希望在查看数据时能把字段备注放到任意位置对照阅读，同时减少对表格数据的遮挡。

## 目标

- 仅改变全屏表窗口中的 Schema 信息展示方式，普通表详情模式保持现有布局。
- 全屏下 Schema 展开后显示为可拖动的小窗口。
- 小窗口可以调整宽高，并在表窗口尺寸变化时保持可见、可用。
- 字段类型列可通过窗口内按钮隐藏或显示，以便节省横向空间。
- 继续保留表备注、字段名、备注、高亮命中、表内搜索入口、Schema 收起入口和现有字段列宽调整能力。

## 推荐方案

在现有 `schema-box` 基础上做全屏增强，而不是拆新组件。全屏且 Schema 展开时，`schema-box` 切换为绝对定位浮窗；非全屏或折叠时继续沿用现有结构。

### 交互

- 顶部全屏工具栏的 `Schema` 按钮继续控制打开/收起。
- 浮窗标题栏显示“Schema 信息”，并作为拖拽手柄。
- 标题栏右侧提供：
  - “搜索”：复用当前表内查找入口。
  - “隐藏类型/显示类型”：切换字段类型列显隐。
  - “收起”：关闭 Schema 浮窗。
- 用户拖动标题栏移动窗口；窗口被限制在表格全屏容器内，避免拖出可视范围。
- 用户通过右下角或原生 resize 调整窗口大小；宽高有最小值和最大边界，避免过小不可读或超出窗口。

### 布局与适配

- 浮窗默认位置在表窗口左上区域但避开主标题栏，例如 `left: 16px; top: 48px`。
- 默认尺寸约为 `520px × 320px`，但会根据容器尺寸 clamp 到可视范围。
- 最小尺寸约为 `320px × 180px`，便于保留标题栏、表备注和至少两列表格内容。
- 表窗口尺寸变化、全屏切换、UI 缩放变化后，对浮窗位置和尺寸做边界校正。
- 浮窗内容区域独立滚动，不影响底层数据表滚动。

### 字段类型隐藏

- 新增 `schemaTypeHidden` 状态。
- 类型隐藏时：
  - `colgroup`、`thead` 和每行的类型单元格不渲染或不显示。
  - Schema 表格变为“字段名 / 备注”两列。
  - 按钮文本显示“显示类型”。
- 类型显示时保留现有三列和字段列宽调整逻辑。

### 状态管理

新增全屏 Schema 浮窗状态：

- `fullscreenSchemaWindow.left`
- `fullscreenSchemaWindow.top`
- `fullscreenSchemaWindow.width`
- `fullscreenSchemaWindow.height`
- `schemaTypeHidden`

这些状态仅影响当前前端会话，不需要持久化到配置文件；切换表标签时可沿用当前浮窗位置和类型显隐偏好，减少重复调整。

### 测试与验证

- 全屏打开完整表视图，点击 `Schema` 后出现可拖动小窗口。
- 拖动到四角附近时不会离开可视区域。
- 调整大小后内容可滚动，底层表格仍可滚动和操作。
- 点击“隐藏类型”后只显示字段名和备注；再次点击恢复类型列。
- 普通非全屏 Schema 展开/收起保持现有行为。
- 表内搜索仍能高亮 Schema 中的表备注和字段行。
