# 表格冻结功能设计

## 目标

在表格界面增加类似表格软件的冻结功能：用户可以冻结从最左侧到某个字段的列，也可以冻结从第一行到某一行的行，方便横向或纵向滚动时保留关键上下文。

## 交互设计

### 字段冻结

- 每个字段表头右侧增加一个小冻结按钮，位置在字段名和现有列宽拖拽区域之间。
- 按钮默认低透明度，鼠标移入表头时变清晰，避免占用密集表格的注意力。
- 点击某字段的冻结按钮后，冻结从最左数据字段到当前字段的所有数据列。
- 如果再次点击当前冻结字段，则取消列冻结。
- 点击其他字段的冻结按钮会移动冻结边界。

### 行冻结

- 表格最左侧保留或新增一条窄行操作列。
- 编辑模式下复用现有行柄列；非编辑模式下新增同宽行柄列。
- 鼠标移入某一行时，在行柄列显示小冻结按钮。
- 点击第 N 行的冻结按钮后，冻结表头下方从第 1 行到第 N 行。
- 如果再次点击当前冻结行，则取消行冻结。
- 点击其他行的冻结按钮会移动冻结边界。

### 冻结状态展示

- 冻结列边界右侧显示较明显的竖向分隔线。
- 冻结行边界下方显示较明显的横向分隔线。
- 当前冻结边界上的按钮保持 active 状态。
- 冻结状态只作用于当前表格视图和当前分页，不持久化到配置；切换表、刷新数据或重新查询时清空，避免状态错乱。

## 技术设计

### 状态

在 `src/App.vue` 中增加：

- `frozenColumnName`：当前列冻结边界字段名，空值表示未冻结列。
- `frozenRowIndex`：当前行冻结边界索引，空值表示未冻结行。

### 列冻结布局

- 继续使用现有表格结构和滚动容器。
- 根据 `tableView.columns`、现有行操作列宽、checkbox 列宽、字段宽度计算每列 sticky left 偏移。
- 冻结范围内的表头单元格和数据单元格设置 `position: sticky` 与对应 `left`。
- 冻结边界列增加边界 class。
- 需要兼容编辑模式下的行柄列与 checkbox 列，确保数据列 left 偏移正确。

### 行冻结布局

- 表头仍 sticky 在顶部。
- 冻结范围内的普通数据行设置 sticky top，top 从表头高度之后开始累加。
- 行冻结只覆盖当前页 `tableView.rows`，不覆盖新增行。
- 冻结边界行增加边界 class。

### 样式

新增或扩展样式：

- `.freeze-btn`：统一冻结按钮外观。
- `.column-freeze-btn`：表头冻结按钮。
- `.row-freeze-btn`：行冻结按钮。
- `.frozen-col` / `.frozen-col-edge`：冻结列背景和边界。
- `.frozen-row` / `.frozen-row-edge`：冻结行背景和边界。

样式应延续当前表格的浅色、蓝色 accent、低干扰 hover 体系。

## 测试设计

### 自动测试

将可测试逻辑抽为纯函数后增加 Node 内置测试：

- 给定列列表、列宽、冻结字段，计算哪些列被冻结、sticky left 值和边界列。
- 给定行索引、冻结行索引，计算哪些行被冻结、sticky top 值和边界行。
- 覆盖编辑模式与非编辑模式的行操作列偏移差异。

### 手动验证

- 普通表格：列冻结、行冻结、同时冻结列和行。
- 编辑模式：行柄列、checkbox 列、单元格编辑、选区与冻结视觉不冲突。
- 横向滚动：冻结列保持在左侧且边界清晰。
- 纵向滚动：冻结行保持在表头下方且边界清晰。
- 再次点击当前冻结按钮可以取消。
- 切换表、刷新数据或重新查询后冻结状态清空。
