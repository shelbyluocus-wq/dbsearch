# F7 / F8 快捷粘贴工具 UI UX 设计文档

## 1. 产品名称

**快捷粘贴管理器 / Quick Paste Manager**

---

## 2. 产品定位

这是一个面向桌面端的快捷粘贴工具，主要用于保存、管理并快速输出多条常用文本或图片内容。

用户可以通过 **F7** 打开一个粘贴管理界面，在界面中选择、编辑、添加、删除、预览文本或图片片段，并可将其中一条设置为默认内容。

用户也可以通过 **F8** 不打开界面，直接将默认内容输出到当前光标所在位置。

---

## 3. 核心使用场景

### 3.1 高频文本快速输出

例如：

- 客服常用回复
    
- 联系方式
    
- 邮箱地址
    
- 游戏配置说明
    
- 工作中常用的备注文本
    
- 固定格式的反馈内容
    
- 常用指令、代码片段、Prompt
    

### 3.2 图片快速输出

例如：

- 常用截图
    
- 表情包
    
- Logo
    
- 工作说明图
    
- 设计参考图
    
- 常用 UI 标注图
    

### 3.3 默认内容快速输出

用户可以把最常用的一条内容设为默认项。

之后只需按 **F8**，不打开界面，系统就会直接输出这条默认内容。

---

# 4. 快捷键逻辑

## 4.1 F7：打开粘贴界面

按下 **F7** 后，弹出一个 macOS 风格的浮层窗口。

该窗口不应是普通全屏应用，而是类似 Spotlight、Raycast、Alfred、PopClip 的轻量级悬浮工具窗口。

### F7 打开后用户可以做的事情

- 搜索已保存内容
    
- 查看所有文本和图片片段
    
- 新增文本或图片
    
- 点击某条内容直接输出
    
- 设置某条内容为默认项
    
- 编辑某条内容
    
- 删除某条内容
    
- 复制某条内容
    
- 查看内容预览
    
- 管理分类和常用项
    

---

## 4.2 F8：直接输出默认内容

按下 **F8** 后，不打开任何主界面。

系统直接将当前默认内容输出到当前光标位置。

### F8 行为规则

|默认内容类型|F8 行为|
|---|---|
|文本|直接粘贴文本到当前输入框|
|图片|直接粘贴图片到当前可粘贴区域|
|无默认内容|弹出轻提示：尚未设置默认内容|
|当前窗口不可粘贴|弹出轻提示：当前位置不支持粘贴|
|默认内容已被删除|自动取消默认状态，并提示用户重新设置|

# 5. 目标用户

## 5.1 核心用户

- 经常需要复制粘贴固定文本的人
    
- 客服、运营、策划、编辑、程序员
    
- 需要频繁发送固定图片或表情的人
    
- 希望减少重复输入的人
    
- 喜欢使用快捷键提高效率的桌面用户
    

## 5.2 用户痛点

### 痛点一：常用内容太多，复制来源分散

用户经常要从不同文档、聊天记录、文件夹里找内容，效率很低。

### 痛点二：系统剪贴板历史不够可控

系统剪贴板历史一般是临时的，用户无法长期保存、分类和设置默认内容。

### 痛点三：图片粘贴不方便

很多工具只支持文本片段，不方便保存和快速输出图片。

### 痛点四：最常用内容还要重复打开界面选择

所以需要 F8 直接输出默认内容。

# 6. 产品核心目标

## 6.1 功能目标

- 支持保存多条文本内容
    
- 支持保存多张图片内容
    
- 支持搜索内容
    
- 支持一键输出某条内容
    
- 支持设置默认内容
    
- 支持 F8 快捷输出默认内容
    
- 支持编辑、复制、删除
    
- 支持分类筛选
    
- 支持内容预览
    

## 6.2 体验目标

- 界面轻量、快速、低打扰
    
- 操作路径短
    
- 视觉风格接近 macOS
    
- 用户无需学习复杂规则
    
- 常用操作可以通过键盘完成
    
- 鼠标用户也能直观使用

# 7. 整体界面风格

## 7.1 视觉关键词

- macOS
    
- Liquid Glass
    
- 半透明磨砂玻璃
    
- 圆角窗口
    
- 柔和阴影
    
- 清爽留白
    
- 轻量工具感
    
- 高级、克制、低干扰
    
- 类似 Raycast / Apple Notes / Finder 侧边栏风格
    

---

## 7.2 设计基调

整体界面应采用 **macOS 现代工具型应用风格**。

不要做成厚重的 Windows 软件，也不要做成网页后台系统。

界面应该像一个轻量、精致、浮在当前工作流之上的快捷工具。

---

# 10. 左侧分类栏设计

## 10.1 分类项目

左侧分类栏用于筛选内容。

推荐分类如下：

|分类|图标|含义|

|文本|文档图标|只显示文本片段|
|图片|图片图标|只显示图片片段|
|常用|星标图标|用户收藏的内容|
|默认|金色星标图标|当前默认输出内容|

---

## 10.2 分类项视觉状态

每个分类项包含：

- 图标
    
- 分类名称
    
- 数量徽标
    

示例：

```text
▣ 全部      12
▤ 文本       8
▧ 图片       4
☆ 常用       6
★ 默认       1
```

---

## 10.3 选中状态

选中分类时：

- 背景变为浅蓝色半透明
    
- 左侧出现蓝色竖线
    
- 图标和文字变为蓝色
    
- 数量徽标变为蓝色浅底
    

---

## 10.4 左侧底部提示区

左下角显示快捷键提示：

```text
提示

```

# 11. 中间内容列表区设计

## 11.1 内容列表结构

中间区域是用户最常操作的区域。

每条内容以卡片形式展示。

每个卡片包含：

- 内容标题或摘要
    
- 内容类型标签
    
- 是否默认标签
    
- 是否收藏星标
    
- 更新时间
    
- 图片缩略图，若是图片内容
    
- 选中状态边框
    

---

## 11.2 文本卡片样式

文本卡片示例：

```text
┌─────────────────────────────────────┐
│ 感谢您的支持与信任，我们会继续努力…      ★ │
│ 文本 · 默认                         今天 10:30 │
└─────────────────────────────────────┘
```

### 文本内容显示规则

- 第一行显示内容摘要
    
- 最多显示 1 到 3 行
    
- 超出部分使用省略号
    
- 如果用户填写了标题，则优先显示标题
    
- 如果没有标题，则使用正文前 20 到 30 个字作为标题
    

---

## 11.3 图片卡片样式

图片卡片示例：

```text
┌─────────────────────────────────────┐
│ ┌──────────────┐ 风景图片              ☆ │
│ │ 图片缩略图     │ 图片                 2024/05/20 │
│ └──────────────┘                         │
└─────────────────────────────────────┘
```

### 图片显示规则

- 显示小尺寸缩略图
    
- 右侧显示图片名称
    
- 下方显示类型标签“图片”
    
- 支持 PNG、JPG、JPEG、WEBP、GIF
    
- 如果是 GIF，角落显示“GIF”标记
    

---

## 11.4 选中状态

当前选中的内容卡片：

- 外边框为 macOS 蓝色
    
- 背景轻微蓝色渐变
    
- 右上角星标高亮
    
- 内容标签清晰可见
    

---

## 11.5 默认内容标记

被设置为默认内容的卡片应显示：

```text
文本 · 默认
```

或者显示一个小徽标：

```text
默认
```

推荐使用浅蓝色或金色小标签。

---

## 11.6 收藏状态

收藏按钮显示在卡片右上角：

|状态|显示|
|---|---|
|未收藏|空心星标|
|已收藏|实心蓝色或黄色星标|

# 12. 右侧预览与操作区设计

## 12.1 右侧区域结构

右侧区域分为四块：

```text
内容预览
操作按钮
管理按钮
元信息
```

---

## 12.2 内容预览区

### 文本预览

显示完整文本内容。

样式要求：

- 白色或半透明浅色卡片
    
- 圆角 12px - 16px
    
- 内边距 16px
    
- 文本可滚动
    
- 支持换行
    
- 支持长文本
    

示例：

```text
内容预览

┌──────────────────────────────┐
│ 感谢您的支持与信任，             │
│ 我们会继续努力为您提供更好的服务！ │
└──────────────────────────────┘
```

---

### 图片预览

图片内容应显示大图预览。

要求：

- 保持原始比例
    
- 最大宽度填满预览卡片
    
- 最大高度限制
    
- 背景使用浅灰棋盘格或白色
    
- 图片圆角 10px
    

---

## 12.3 主操作按钮

主操作按钮为最重要操作：

```text
→ 输出到当前位置
```

### 按钮视觉

- 蓝色渐变背景
    
- 白色文字
    
- 圆角 12px
    
- 高度 48px
    
- 图标 + 文案
    
- 右侧显示快捷键提示：⌘ + Enter
    

---

## 12.4 设置默认按钮

第二重要操作：

```text
☆ 设为默认
```

当该项已经是默认内容时，显示：

```text
★ 已设为默认
```

并且按钮呈现弱高亮状态。

---

## 12.5 管理操作区

管理操作包含：

|操作|图标|说明|
|---|---|---|
|编辑|铅笔|修改文本、标题或图片名称|
|复制|复制图标|复制到系统剪贴板，但不直接输出|
|删除|垃圾桶|删除该条内容|

布局建议：

```text
┌────────┬────────┬────────┐
│ 编辑   │ 复制   │ 删除   │
└────────┴────────┴────────┘
```

## 12.6 元信息区

类型：文本
大小：1.2 KB

# 13. 新增内容流程

## 13.1 新增按钮

点击顶部 `+` 按钮后，弹出新增内容面板。

可以是右侧抽屉，也可以是居中弹窗。

推荐使用居中弹窗。

---

## 13.2 新增弹窗结构

```text
┌──────────────────────────────┐
│ 新增粘贴内容                    │
│                              │
│ 类型： 文本 / 图片               │
│ 标题： [ 输入标题，可选 ]          │
│ 内容： [ 多行文本输入框 ]          │
│                              │
│ □ 添加到常用                    │
│ □ 设为默认                      │
│                              │
│ 取消              保存          │
└──────────────────────────────┘
```

---

## 13.3 新增文本

用户选择“文本”类型时：

- 显示多行文本输入框
    
- 支持换行
    
- 支持粘贴长文本
    
- 标题可选
    
- 如果标题为空，自动用正文开头作为标题
    

---

## 13.4 新增图片

用户选择“图片”类型时：

支持三种方式：

- 拖拽图片到上传区域
    
- 点击选择本地图片
    
- 直接从剪贴板粘贴图片
    

上传区域示例：

```text
┌──────────────────────────────┐
│     拖拽图片到这里              │
│     或点击选择图片              │
│     支持 PNG / JPG / WEBP / GIF │
└──────────────────────────────┘
```

# 15. 删除内容流程

点击删除后，不应立即删除。

需要二次确认。

```text
确定删除这条内容吗？

删除后不可恢复。

取消    删除
```

### 删除规则

- 如果删除的是普通内容，直接删除
    
- 如果删除的是默认内容，删除后默认内容为空
    
- 删除默认内容后提示：默认内容已被删除，请重新设置

# 18. F8 输出反馈设计

按下 F8 后，应该出现一个轻量提示卡片，不打断用户。

## 18.1 成功状态

```text
✓ 已输出默认内容

感谢您的支持与信任，我们会继续努力
```

### 视觉要求

- 出现在屏幕右上角或中央偏上
    
- 圆角卡片
    
- 半透明白色背景
    
- 轻微阴影
    
- 绿色成功图标
    
- 1.5 秒后自动消失
    

---

## 18.2 无默认内容状态

```text
尚未设置默认内容

按 F7 打开粘贴界面，选择一条内容设为默认。
```

---

## 18.3 输出失败状态

```text
当前位置不支持粘贴

请先点击一个可输入区域后再试。
```

---

# 33. 最终设计效果总结

这个工具的界面应该让用户一眼理解：

```text
F7 = 打开管理和选择界面
F8 = 不打开界面，直接输出默认内容
```

主界面重点不是“复杂管理”，而是“快速选择、快速输出、快速设默认”。

因此 UI 的核心优先级是：

1. 当前选中的内容要清楚
    
2. 默认内容要清楚
    
3. 输出按钮要明显
    
4. 搜索要方便
    
5. 新增和管理不要打扰主流程
    
6. 整体要像 macOS 原生轻工具，而不是复杂后台系统
